📊 HR Analytics & Employee Insights using PostgreSQL

📌 Project Overview

This project focuses on analyzing employee data using PostgreSQL and SQL to uncover meaningful HR insights related to employee attrition, salary, job roles, departments, satisfaction, experience, overtime, and workforce performance.

The project contains 1,470 employee records and 35 HR-related attributes, providing a practical dataset for developing SQL and analytical skills.

📈 Key Analytical Questions

Some of the major questions addressed include:

1. Which departments have higher employee attrition?
2. Which departments have the highest average salary?
3. Which employees rank highest by salary?
4. Who are the top employees within each department?
5. How does an employee's salary compare with their department average?
6. What percentage of total departmental income is contributed by each employee?
7. How does salary differ from the previous employee?
8. What is the running average salary within a department?
9. Which job roles have the highest income?
10. Which job role provides the best combination of salary, low attrition and job satisfaction?

🏆 Job Role Scoring

The final analysis creates a scoring system for job roles using:

- Average monthly income
- Attrition rate
- Job satisfaction

The three metrics are converted into percentile-based scores and combined to create an overall job-role score and ranking.
